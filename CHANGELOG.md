# Changelog

## 1.0.0 - 2026-11-17

### Added

- Standalone Fabric mod for Minecraft 1.21.11.
- Seed-based overworld, Nether and End ore simulation.
- Native Minecraft GUI with `F8` open and `F9` toggle keybinds.
- Ten toggleable ore groups.
- Coloured dust particles and optional tracers.
- Deepslate-only filter and per-chunk cache.
- Persistent settings in `config/champ-seed-xray.json`.
- Mod icon, screenshot, README, MIT license and security notes.
- Release jar and sources jar.
